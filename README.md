## FAQ

### Is VideoPatch safe to use on my computer?

VideoPatch is a clean utility tool that modifies local application files on your Windows system. Always download from the official repository and scan with your preferred anticomponent software before use.

### Which versions of the supported video editors are compatible?

VideoPatch supports the latest stable releases of CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. Check the compatibility table in the documentation for specific version numbers.

### Why do I need to run videopatch.exe as administrator?

Administrator privileges are required because VideoPatch needs to write modified configuration files to protected program directories where video editors are installed.

### What happens if a supported video editor receives an update after patching?

Software updates may overwrite the patched files, requiring you to re-run VideoPatch on the updated version. We recommend disabling automatic updates temporarily after activating.

### Can I use VideoPatch on macOS or Linux operating systems?

No, VideoPatch is a Windows-only desktop application designed to work exclusively with Windows-based video editing software installations.

### How do I uninstall or reverse the changes made by VideoPatch?

Reinstalling the video editor from its official installer will restore the original unpatched files, effectively reversing all modifications made by VideoPatch.

### Why is the extraction password required to open the ZIP archive?

The password protection helps prevent automated scanning and ensures that users intentionally access the software, reducing unwanted distribution on file-sharing platforms.

### Does VideoPatch work with portable or USB-installed versions of editors?

VideoPatch is designed for standard Windows installations. Portable versions may require manual path configuration within the tool if they are not automatically detected.

### Will VideoPatch slow down my video editing software performance?

No, VideoPatch only modifies feature access flags and does not alter the core rendering engine or performance characteristics of the supported video editors.
